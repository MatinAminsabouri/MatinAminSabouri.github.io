      AI Systems / RAG

      Ravin — On-Premise Municipal AI Assistant

      The first specialized municipal AI assistant in Iran with Persian NLP, RAG, and Speech-to-Text, deployed entirely on-premise.

      The Challenge & Hard Constraints

      Municipal inquiries required interpreting complex, localized urban planning regulations with zero external cloud dependencies, no internet access (strict air-gapped security), and limited on-premise compute/VRAM.

      Engineered Pipeline

      Persian Voice/Text -> Offline ASR (Sherpa) -> Semantic Chunking & Vector Search -> dotnet Orchestrator -> Local LLM + Strict Guardrails

      Key Architectural Decisions & Evidence

      • Decoupled Executiondotnet Core handles deterministic business logic & API gateways; Python manages local model inference & embeddings.
      • Zero-Hallucination RAGHybrid retrieval combining exact rule matching with dense vector embeddings stored in on-premise storage.
      • Resilient Audio ProcessingLow-latency streaming ASR tuned for noisy administrative environments.
